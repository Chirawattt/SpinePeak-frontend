# SpinePeak — content JSON (แก้ล่าสุด 27 ก.ย. 2569 เย็น)

ชุดข้อมูลของเฟส 1 แปลงจาก Google Sheet "SpinePeak - รายชื่อคอร์สทั้งหมด" ตามที่ตกลงไว้ใน
`spinepeak-data-schema.md` ข้อมูลผ่านการตรวจแล้ว **0 ข้อผิดพลาด**

```
raw/courses.csv            แท็บ "คอร์สทั้งหมด" (44 แถว) ตามที่โหลดมาจากชีต
raw/sets.csv               แท็บ "SET" (27 แถว)
raw/legend.csv             แท็บ "คำอธิบายสี"
tools/sheet-sync/
  sheet_sync.py            สคริปต์แปลง + ตรวจ
content/courses.json       44 คอร์ส    สร้างจากชีต ห้ามแก้มือ
content/sets.json          27 SET      สร้างจากชีต ห้ามแก้มือ
content/site.json          ข้อความบนเว็บ ผู้สอน ช่องทางติดต่อ FAQ — แก้มือ
content/reviews.json       [] ยังไม่มีรีวิว — แก้มือ
content/clips.json         [] ยังไม่มีคลิปตัวอย่าง — แก้มือ
content/cover-images-needed.txt   ชื่อไฟล์รูป 44 รูปที่ชีตอ้างถึงแต่ยังไม่มีไฟล์
```

## วิธีอัปเดตเมื่อแก้ชีต

1. เปิดชีต > ไฟล์ > ดาวน์โหลด > CSV แล้ววางทับ `raw/courses.csv` และ `raw/sets.csv`
2. `python3 tools/sheet-sync/sheet_sync.py`
3. ถ้ามีข้อผิดพลาด สคริปต์จะไม่เขียนไฟล์และบอกว่าต้องแก้อะไรในชีต

`sheet_sync.py --check` ตรวจเฉย ๆ ไม่เขียนไฟล์ ใช้ตอน sync บนเครื่อง
สามไฟล์ที่เขียนด้วยมือ (`site.json`, `reviews.json`, `clips.json`) สคริปต์ไม่แตะต้อง

## ด่านตรวจตอน build

`npm run build` (รวมถึงบน Vercel ที่ไม่มี Python) รัน `npm run check:content` ก่อนเสมอ
ซึ่งเรียก `validateContent()` ใน `src/catalog/` กับข้อมูลใน `content/` ถ้าเจอปัญหา build จะพังและแสดงรายการ
`where` (ชิ้นที่ผิด เช่น `เซ็ต PR-01 (primary-p4-bundle)`) กับ `message` (ผิดอะไร)

ตรวจ: slug ซ้ำ (ในคอร์ส ในเซ็ต และข้ามกัน) · slug ผิดรูปแบบ · slug เซ็ตไม่ลงท้าย `-bundle` หรือ slug คอร์สลงท้าย `-bundle` ·
เซ็ตอ้างคอร์สที่ไม่มี · เซ็ตว่างหรือใส่คอร์สซ้ำ · รหัสเซ็ตซ้ำ ไม่มีอยู่ หรือคอร์สระบุซ้ำ ·
`setCodes` ของคอร์สกับ `courseSlugs` ของเซ็ตไม่ตรงกัน (สองทาง) · กลุ่ม วิชา สถานะ การขาย ที่ไม่รู้จัก ·
คอร์สขายเดี่ยวเท่านั้นที่อยู่ในเซ็ต · คอร์สขายเดี่ยวและในเซ็ตที่ไม่อยู่ในเซ็ตไหนเลย · ผู้สอนที่ไม่มีใน `site.json`

ตรวจเร็ว ๆ โดยไม่ build: `npm run check:content`

## สิ่งที่สคริปต์ตรวจ

หยุดทันที (ไม่เขียนไฟล์): slug ว่างหรือผิดรูปแบบ · slug ซ้ำหรือชนกันข้ามตาราง · ชื่อคอร์สซ้ำ ·
กลุ่ม วิชา การขาย สถานะ ที่ไม่รู้จัก · ราคาผิด · tagline ว่าง · SET อ้าง slug หรือชื่อคอร์สที่ไม่มี ·
**คอลัมน์ "slug คอร์สที่รวม" ไม่ตรงกับคอลัมน์ "คอร์สที่รวม" ที่เป็นชื่อไทย** · จำนวนคอร์สไม่ตรงกับรายการ ·
ราคา SET ไม่ถูกกว่าซื้อแยก · คอร์ส "ขายเดี่ยวเท่านั้น" ที่ไปโผล่ใน SET ·
คอลัมน์ "อยู่ใน SET" ไม่ตรงกับแท็บ SET (ตรวจสองทาง) · `site.json` ขาดผู้สอนหรือกลุ่มที่คอร์สอ้างถึง ·
`site.json` ไม่มีทั้ง LINE OA และเพจ Facebook · LINE basicId ไม่ขึ้นต้นด้วย @ · ลิงก์โซเชียลที่ไม่ใช่ https

เตือนแต่ไปต่อ: ราคาปกติในชีตไม่เท่าผลรวมราคาคอร์สสมาชิก (เว็บใช้ผลรวมที่คำนวณได้เสมอ) ·
สองคอลัมน์สมาชิกเรียงลำดับไม่เหมือนกัน (ใช้ลำดับของคอลัมน์ slug) · คอร์สที่ไม่มีรายการบท ·
คอร์สที่ไม่มีตัวเลขสักตัว · ยังไม่มีเวลาทำการของแอดมิน

## สิ่งที่ตั้งใจไม่เก็บในไฟล์

ราคาปกติ ส่วนลด เปอร์เซ็นต์ ยอดรวม จำนวนคอร์สใน SET การตัดสินใจโชว์ป้ายประหยัด
และตัวเลือกใน dropdown ตัวกรอง ทั้งหมดคำนวณตอน build จากราคาคอร์สจริง เพราะถ้าเก็บไว้ในไฟล์
วันที่แก้ราคาคอร์สเดียว ตัวเลขส่วนลดของ SET ที่มีคอร์สนั้นจะเพี้ยนเงียบ ๆ ทุกตัว

สคริปต์พิมพ์ค่าที่คำนวณได้ออกมาให้ตรวจตาทุกครั้งที่รัน ตอนนี้ SET 23 ตัวโชว์ป้ายประหยัด
และ 4 ตัวถูกซ่อน (PR-01, PR-02, PR-03, PR-05 ประหยัดแค่ 10-20 บาท คิดเป็น 1%)

และวัดยอดได้แม้ลูกค้าจะบล็อกสคริปต์ติดตาม รูปแบบลิงก์ปลายทาง

```

       ข้อความตั้งต้นมาจาก contact.line.prefillTemplate แทน {itemTitle} ด้วยชื่อคอร์สหรือชื่อ SET
```

## ข้อควรรู้เกี่ยวกับข้อมูลชุดนี้

- **สองตารางเชื่อมกันด้วย slug แล้ว** คอลัมน์ "slug คอร์สที่รวม" (คั่นด้วยจุลภาค) เป็นตัวจริง
  คอลัมน์ "คอร์สที่รวม" ที่เป็นชื่อไทยเก็บไว้ให้คนอ่าน และสคริปต์ใช้เป็นการตรวจซ้ำ
  ถ้าแก้ไปแค่คอลัมน์เดียว สคริปต์จะหยุดและบอกว่า SET ไหนไม่ตรง ตอนนี้ทั้ง 27 SET ตรงกันทั้งสองคอลัมน์
  ถ้าคอลัมน์ slug ว่าง สคริปต์จะเตือนแล้วถอยไปใช้ชื่อไทยแทน ยังทำงานได้
- **คอลัมน์ไฟล์ PDF รับค่าเป็นช่วงได้** คอร์สปรับพื้นฐานเขียน "30-70" และ "55-90"
  ออกมาเป็น `{"min":30,"max":70}` หน้าเว็บต้องแสดงเป็น "30-70 หน้า"
- **ไม่ใช่ทุกคอร์สมีตัวเลขครบสามตัว** เช่น NETSAT ปี 66 และ 67 มีแค่จำนวนข้อ
  คอร์สเนื้อหาประถมไม่มีจำนวนข้อ ฟิลด์ที่ไม่มีจะไม่ปรากฏใน JSON เลย
  หน้าเว็บต้องซ่อนช่องนั้นไป **ห้ามแสดง "0 ชม." หรือช่องว่าง**
- **`chapters` มีแค่ 15 คอร์ส** คือคอร์สที่คอลัมน์รายละเอียดขึ้นต้นด้วย "เนื้อหา:"
  อีก 29 คอร์สเป็นคอร์สตะลุยโจทย์ที่ไม่มีบท บล็อกรายการบทในหน้า detail ต้องซ่อน
- **`topics` (หัวข้อ) มาจากคอลัมน์ "หัวข้อ"** ในแท็บคอร์สทั้งหมด หลายค่าคั่นด้วย `,` ถ้าเว้นว่างใช้ `[category]`
  ตอนนี้ชีตยังไม่มีคอลัมน์นี้ ทุกคอร์สจึงมีหัวข้อเท่ากับหมวดหมู่ (ค่าที่ควรใส่อยู่ใน issue #14)
- **`previewVideoUrl` มาจากคอลัมน์ "คลิปตัวอย่าง"** (ลิงก์ YouTube) ถ้าว่างหน้าคอร์สซ่อนกล่องคลิป
  ตอนนี้มีคลิป mock คอร์สเดียว (foundation-biology-m4-term-1) ซึ่งจะหายไปเองตอน sync ครั้งถัดไป (ดู issue #14)
- **แถวที่สถานะไม่ใช่ "เปิดขาย" ไม่ขึ้นเว็บ** สคริปต์ข้ามแถวนั้นไปเลย ถ้ามี SET ที่ยังใส่คอร์สนั้นอยู่จะแจ้งให้แก้
- **`subject` มี 6 ค่า** ไม่ใช่ 5 อย่างที่เอกสารรุ่นแรกเขียนไว้ เพราะ A-Level วิทย์ประยุกต์
  ใช้วิชา `วิทยาศาสตร์ประยุกต์` → `applied_science`
- **ผู้สอนที่เว้นว่างในชีตแปลงเป็นครูพี่หนามทั้งหมด** ตามที่เจ้าของยืนยัน
  ตอนนี้ครูพี่หนาม 42 คอร์ส ครูพี่ฝน 1 ครูพี่ลูกไม้ 1
