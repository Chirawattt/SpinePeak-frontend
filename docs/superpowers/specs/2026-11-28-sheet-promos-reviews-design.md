# โปรโมชันและรูปรีวิวจาก Google Sheet (short design)

## เป้าหมาย
ทำตามใบเสนอราคาข้อ 2.2: เจ้าของแก้โปรโมชันและรีวิวในชีต รัน sync แล้วเว็บอัปเดต โดยไม่ต้องแก้โค้ดหรือก๊อปไฟล์เอง

## ทางเลือก
1. **เลือก:** สคริปต์เขียน `content/promos.json` และ `content/review-images.json` แล้ว `src/content.ts` เอา promos ใส่กลับเป็น `site.promos` โค้ดแสดงผลเดิมแทบไม่ต้องแก้
2. สคริปต์เขียนทับ `site.json` > `promos`: ไฟล์น้อยกว่า แต่ไปจัดรูปแบบไฟล์ที่แก้ด้วยมือใหม่ทั้งไฟล์
3. เว็บดึงชีตเองตอน build: ไม่ต้องรันสคริปต์ แต่ต้องย้ายตัวตรวจข้อมูลมาเป็น TypeScript และ build พังได้ถ้าชีตล่ม

## แท็บ "โปรโมชัน" (1 แถว = 1 โปร · ลำดับแถว = ลำดับสไลด์ โดยโปรตามฤดูมาก่อน)
| คอลัมน์ | ใช้กับ | ความหมาย |
|---|---|---|
| ชนิด | ทุกแถว | `ตามฤดู` / `ตลอดปี` / `ประหยัด SET` |
| ชื่อโปร | ทุกแถว | ชื่อที่ลูกค้าบอกแอดมิน |
| หัวการ์ด | ตามฤดู | ขึ้นบรรทัดใหม่ในช่อง = ขึ้นบรรทัดบนการ์ด · ว่าง = ใช้ชื่อโปร |
| รายละเอียด | ทุกแถว | บรรทัดเล็กใต้หัว |
| ตัวเลขใหญ่ | ตลอดปี | เช่น `100.-` |
| วันหมดเขต | ตามฤดู | `31/12/2569` หรือ `2026-12-31` · หมดเขตสิ้นวันเวลาไทย |
| รูปแนวนอน | ไม่บังคับ | ลิงก์ Drive ของรูป 3:1 |
| รูปมือถือ | ไม่บังคับ | ลิงก์ Drive ของรูป 4:5 |
| สถานะ | ทุกแถว | `แสดง` / `ซ่อน` |

## แท็บ "รีวิว" (1 แถว = 1 การ์ดบนหน้าแรก)
| คอลัมน์ | ความหมาย |
|---|---|
| slug | slug ของคอร์สหรือ SET · ห้ามซ้ำ |
| รูปปก | ลิงก์ Drive 1 รูป (16:9) แสดงบนการ์ดหน้าแรก · บังคับ |
| รูปรีวิว | ลิงก์ Drive ของรูปย่อย หลายรูปขึ้นบรรทัดใหม่ในช่องเดียว · แสดงเมื่อกดการ์ด · อย่างน้อย 1 รูป |
| สถานะ | `แสดง` / `ซ่อน` |

ลำดับการ์ดตามลำดับแถว รูปปกไม่ถูกนับเป็นรูปย่อย ชื่อ ลิงก์ และปกคอร์ส (แบนเนอร์ท้ายหน้าต่าง) มาจากคอร์ส/SET เอง ไม่มีแถวที่แสดง = ซ่อนทั้งส่วน (แทน mock ปัจจุบัน)

## รูป
สคริปต์ดาวน์โหลดจาก Drive ไป `public/promos/` และ `public/reviews/` ตั้งชื่อตาม ID ไฟล์ของ Drive (มีแล้วไม่โหลดซ้ำ) รูปต้องแชร์แบบ "ทุกคนที่มีลิงก์" ไฟล์ที่ไม่ใช่รูป = error และไม่เขียน JSON · ไม่ลบไฟล์เก่าให้

## กติกา
- แถวผิด = สคริปต์หยุด ไม่เขียนไฟล์ บอกแถวที่ต้องแก้ (เหมือนคอร์ส)
- แท็บว่าง = ไม่มีโปร / ไม่มีรีวิว
- มีไฟล์สำรอง `raw/promos.csv`, `raw/reviews.csv`
- สร้างแท็บในชีตจริง ใส่โปร "ซื้อเป็น SET" แถวเดียว ไม่ใส่ mock
- ข้อความรีวิว (`reviews.json`) ยังแก้มือเหมือนเดิม
- อัปเดต `docs/content.md`
